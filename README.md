## Selected projects

### [VideoGameCharactersAPI](https://github.com/ConstantineOntoulis/VideoGameCharactersAPI)

An ASP.NET Core Web API for managing video game characters, with **JWT authentication, role-based authorization, DTO validation, filtering, sorting, and pagination**. Uses **Entity Framework Core and SQL Server** for persistence, with **xUnit tests, Docker Compose, and GitHub Actions** for verification and local execution.

A C#/.NET application organized into separate **service, repository, contract, and entity projects**. Includes a test project and ongoing work on repository abstractions and isolated unit testing with **xUnit and Moq**.

A documented progression through **C# fundamentals, debugging, LINQ, console applications, and ASP.NET Core API development**, including a database-backed book review API.
